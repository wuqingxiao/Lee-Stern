## 二次复核（2026-10-29，WP2 §10）

对本包做了反向核查，结论未变，四处表述被更正：

- 外层 $J$ 合法。第 $j$ 个隐藏实验重采 $\rho^*$ 并自带 $R$ 次执行预算，混合之间不共享查询带，不能收拢成 $2Q/2^\rho$；表 3.1 又决定每次尝试恰有一个未开封承诺，故隐藏盐数是 $J$ 而非 $3J$，按 $3J$ 计非 FCSD 和仍是 $-149.748731$。因此 $\rho=384$ 是**保守冻结**（验收线允许的最小 8 倍数是 360），不是唯一可行值。
- 总界相对 $2^{-128}$ 的余量是 **7.9999 位**（由假设 F 的 $2^{-136}$ 决定；总界比 $2^{-136}$ 高 $0.000105$ 位，2026-10-30 勘误原写的 8.0001），非 FCSD 和单独才是 21.7487 位；此前把两者混写成一回事。
- $\log_2|S_C|\approx7571.7$ 是**所有组成上的上界**（坐标在 251 个域值上尽量均分），不是 $n=1024$ 可用组成的取值。按 $n=640$ 三组记录的每坐标密度外推得 $3435.7$–$3852.9<\log_2p^k=4081.4$，所以 $n=1024$ 的乘法度符号未定，WP3 冻结 $C$ 前不得写“见证不由 $(H,s)$ 决定”。
- 通信：安全口径的每轮固定开销是 $3\times64+1+2\times48=289$ 字节，测量口径是 161 字节，$+128$ 字节/轮、$+32\,\mathrm{KiB}$/会话；此前只记了盐的 $+16$ 字节。

## WP3 第一步（2026-10-30）

在 $n=1024,k=512$ 上冻结组成并判定 $\log_2|S_C|$ 与 $\log_2p^k=4081.4303$ 的大小：

- 三个已发表形状按 $1.6$ 缩放到 $n=1024$ 后全部落在 $p^k$ 之下：$\log_2|S_C|=3460.24/3857.72/3886.79$，纤维 $2^{-621.19}/2^{-223.71}/2^{-194.64}$。**唯一原像区，符号由组成决定而非由 $n$ 决定**；$n=640$ 时它们已经是 $2^{-403.60}/2^{-165.08}/2^{-142.86}$。
- 判据是组成熵 $H(C)\ge\tfrac12\log_2 251=3.986$ 位/坐标，即 $t_{\rm eff}\ge15.85$：$t$ 均匀族在 $t=16$（$-48.3$ 位）与 $t=17$（$+37.6$ 位）之间翻转，几何族在 $r^*=0.7291$ 翻转。已发表三形状的首项衰减率是 $0.616/0.699/0.722$，第三个离翻转只有 $0.007$。
- 冻结 `WP3_C_N1024.json`（geometric:2 的 1.6 倍缩放：242 个零、Lee 重量 2025、$\|b\|_2=91.011$、$\|b\|_2/\mathrm{GH}=0.7419$）。格族在 $n=1024$ 的费用 $2^{367.77}$，高出预算 $201.8$ 位，三者中最宽。
- 结构性结论：翻转点处 $\|b\|_2/\mathrm{GH}=1.15\sim1.28>1$，**多见证与短秘密不可兼得**；改用平衡组成会让 G1 与 G2 两个模型同时失效，不是变安全。
- 因此证据风格被限定为"唯一原像问题的算法代价"。WP2 §9 的"期望乘法度约 $2^{3490}$"须删除——它对应 $t_{\rm eff}=168$ 的平衡组成，不是任何已冻结的 $C$。

- **组成论证更正**：coset 走查的代价是 $p^k/\max(1,\text{纤维})$，不是平均纤维。冻结 $C$ 纤维 $<1$，走查 $2^{4081.4}$；换成均匀组成后纤维 $2^{+3490.3}$，走查降到 $2^{591.1}$——**仍高 425.1 位**。所以“均匀组成更不安全”不成立；均匀组成坏掉的是 G1/G2 两个校准模型的适用性（短秘密消失、ISD 的 $\beta$ 标定失效），不是给出更便宜的通用攻击。原 §6 的推理已按此重写。
