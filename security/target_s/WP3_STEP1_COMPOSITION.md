## 0 结论

1. **三个自然候选全部落在唯一原像区。** 把 $n=640$ 的三个已冻结组成按 $1024/640=1.6$ 缩放到 $n=1024$，得 $\log_2|S_C|=$ 3460.24 / 3857.72 / 3886.79，平均纤维（每个可达综合征的见证数）为 $2^{-621.19}$ / $2^{-223.71}$ / $2^{-194.64}$。真实公钥的纤维以 $1-2^{-194}$ 以上的概率恰含一个元素。**这个符号由组成决定，不由 $n$ 决定**：$n$ 从 640 到 1024 只是把缺口从 143–404 位扩大到 195–621 位。

2. **判据可化成一句设计规则。** 因 $k=n/2$，$|S_C|\ge p^k$ 当且仅当组成的每坐标熵

   $$H(C)\ \ge\ \frac{k}{n}\log_2 p\ =\ \tfrac12\log_2 251\ =\ 3.986\ \text{位},$$

   即有效字母表 $t_{\rm eff}=2^{H}\ge15.85$。$t$ 值均匀族在 $t=16$（$2^{-48.3}$）与 $t=17$（$2^{+37.6}$）之间翻转；几何衰减族在 $r^*=0.7291$ 处翻转，该点 $t_{\rm eff}=15.854$，与规则吻合到小数点后两位。

3. **冻结 geometric:2 的 1.6 倍缩放**（`WP3_C_N1024.json`，计数前八项 $242,149,93,58,35,22,14,8$）：242 个零、25 个 Lee 值、Lee 重量 2025、$\|b(e)\|_2=91.011$、$\|b\|_2/\mathrm{GH}=0.7419$、$\log_2|S_C|=3460.236$。理由与代价见 §5。

4. **多见证与短秘密不可兼得。** 两个族的翻转点上 $\|b\|_2/\mathrm{GH}$ 分别为 $1.15$ 与 $1.21\sim1.28$，都大于 1。组成平衡到 $|S_C|\ge p^k$ 时，秘密已不比 GH 短：G1 的短向量模型和 G2 的受限球参数同时失去含义。**用组成去买多重度，买到的是"没有模型可用"，不是安全余量。**

## 1 对象与判据

$S_C=\{e\in\mathbb Z_p^n:\#\{j:e_j=a\}=c_a\}$，$|S_C|=n!/\prod_a c_a!$。FCSD 的公开输入是 $(H,s)$ 与公开的 $C$。平均纤维

$$\frac{|S_C|}{p^k}$$

决定整个证据的风格：

- $\gg1$：多见证。"$s$ 可达"几乎不含信息，纤维巨大；计数与信息论风格的论证只在这个区有意义，且必须用对方向。
- $<1$：唯一原像。真实 $s$ 的纤维以 $1-|S_C|/p^k$ 的概率恰为 1，见证由公钥唯一决定，**条件最小熵为 0**。

熵形式 $H\ge(k/n)\log_2p$ 是 Stirling 近似，只作设计规则；符号一律由整数比较判定。

## 5 冻结与理由

**冻结**：`WP3_C_N1024.json`，即 geometric:2 的 1.6 倍缩放（源 `p251_n640_k320_8ee9e91cdd53`，源 SHA-256 记录在文件中）。

理由：

1. **唯一已被端到端校准的几何。** 它的 $n=640$ 版本在 G1 里复算到 $0.01$ 位，1.6 缩放正是 G1 §6 表的前提；换成任何别的形状，G1/G2 的既有数值都不再直接适用。
2. **格族余量最大。** $n=1024$ 下费用 $2^{367.77}$，高出 $2^{166}$ 预算 $201.8$ 位；Ⅱ、Ⅲ 分别只有 $142.2$ 与 $139.0$ 位。
3. **唯一性最稳。** 纤维 $2^{-621}$，不存在"意外第二见证"的模糊地带；Ⅲ 只剩 $2^{-195}$。
4. **与 G2 的机器一致。** $n=640$ 上 full_union 收费最低为 Ⅰ $2^{1135.281}$、Ⅱ $2^{1276.134}$、Ⅲ $2^{1297.821}$，分别高出预算 $969.3/1110.1/1131.8$ 位；Ⅰ 的受限球族余量最小但仍近千位，$n=1024$ 下只会更宽。

代价（必须在第二步定价时一并处理）：

- 秘密是短向量（$0.742\,\mathrm{GH}$），格族模型的"短向量"前提成立——**但这也意味着唯一的保护来自一个启发式范数模型**。
- 每坐标 Lee 重量约 2、只有 25 个 Lee 值，是稀疏+小字母结构。任何代数/小定义域风格的攻击都必须在第二步补价；这正是低熵的另一面。

## 6 证据风格：能写什么、不能写什么

**能写**：

- 唯一原像问题的算法难度：G1 的 BKZ 范数模型、G2 的受限球 ISD。
- "纤维唯一"这一结构事实本身。它排除了反向论证（"多见证所以难"），也排除了 WP2 §5 的私有占位串路线。

**不能写**：

- "预期乘法度 $2^{3490}$""见证熵足够""多见证使求解器难以命中"——在唯一原像区，这些说法方向全错。
- 任何条件的见证最小熵论证：它在唯一原像区恒为 0。
- 把 $|S_C|$ 大当作安全：纤维密度始终是 $1/p^k$，与 $|S_C|$ 无关。

**必须补写**：

- 公钥像只覆盖 $2^{-621}$ 的综合征（可达性极稀）。这是方案的结构性质；它不影响冒充归约（对手总拿到真实公钥），但论文不能再写"$s$ 在 $\mathbb F_p^k$ 上均匀"。
