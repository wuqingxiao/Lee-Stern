# SOUNDNESS_P0：P0 口径下的可靠性论证（经典、单用户、交互式）

## 1. 协议要点（核对自论文 §3.1，第 132 行起）

承诺（每轮三个新盐 ρ1, ρ2, ρ3，各 256 位）：

- cm1 = Hash(σ ‖ Hu ‖ ρ1)
- cm2 = Hash(Pσ(u) ‖ ρ2)
- cm3 = Hash(Pσ(z) ‖ ρ3)，其中 z = e + u

挑战 b ∈ {0,1,2} 均匀，在承诺之后选取。响应与检查：

| b | 响应 | 验证者检查 |
|---|---|---|
| 0 | (σ, u, ρ1, ρ2) | cm1 打开为 (σ, Hu)，cm2 打开为 Pσ(u) |
| 1 | (σ, z, ρ1, ρ3) | cm1 打开为 (σ, Hz − s)，cm3 打开为 Pσ(z) |
| 2 | (v, y, ρ2, ρ3) | v ∈ S_C，cm2 打开为 y，cm3 打开为 v + y |

## 2. 定理 4.2（3-特殊可靠性）复核：成立

设同一承诺 (cm1, cm2, cm3) 对三个挑战都有被接受的响应。

1. b=0 与 b=1 的 cm1 打开：要么得到 SHA-256 碰撞，要么 σ0 = σ1 = σ，且 Hu0 = Hz1 − s。
2. 令 e* = z1 − u0，则 He* = s。
3. b=0 与 b=2 的 cm2 打开：要么碰撞，要么 Pσ(u0) = y2。b=1 与 b=2 的 cm3 打开：要么碰撞，要么 Pσ(z1) = v2 + y2。
4. 于是 Pσ(e*) = v2。验证者已检查 v2 ∈ S_C，而 S_C 在坐标置换下封闭，所以 e* ∈ S_C。

结论：要么抽取出 FCSD 证据 e*，要么在三类承诺之一中得到碰撞。约化损失因子 ≤ 3（猜碰撞出现在哪一类）。不同分支的盐不必相同，因为碰撞的定义只要求两个不同的 (消息, 盐) 有相同摘要。

公开 C 的作用：b=2 新增的 v ∈ S_C 检查正是把 e* 放进 S_C 的那一步。Liu 等原协议没有这一检查，只能得到 e* ∈ S_T（更大的集合），这就是原文组合缺陷的位置。

## 3. 每轮成功率与 N=219

由第 2 节，一个能对同一承诺回答全部 3 个挑战的作弊证明者，可以转化为 FCSD 求解者或 SHA-256 碰撞寻找者。因此在 FCSD 与绑定都未被攻破时，每轮成功率 ≤ 2/3。

N 轮顺序执行（每轮新承诺、新盐、新挑战）：

Pr[冒充成功] ≤ (2/3)^N + Adv_FCSD + Adv_bind

| N | (2/3)^N |
|---:|---:|
| 218 | 2^-127.52（不够） |
| 219 | 2^-128.11（满足） |

所以 P0 取 N = 219。

## 4. 各项代价（P0 = NIST 式“已知最优攻击”口径）

| 项 | 依据 | 位数 |
|---|---|---:|
| 可靠性误差 | (2/3)^219 | 128.11 |
| FCSD | P1 格（悲观叠加最低 core-SVP 244.1 / MATZOV 262.0）、P2 各族 ≥ 2^143 | ≥ 128（余量大） |
| 绑定 | SHA-256 通用经典碰撞 2^128 | 128 |

λ = min(128.11, FCSD, 128) = 128。

## 5. 被动学习不帮助冒充

- 协议 HVZK（论文 §4.3，第 216 行）：诚实会话的记录可被模拟，不泄露 e 的信息，所以窃听不降低 FCSD 难度。
- 冒充时每轮挑战是新鲜均匀的，并在承诺之后选取。历史记录无法预先确定挑战。
- 单个冒充会话的成功概率与用户数量无关，(2/3)^N 一项不随用户数增长。多用户只影响 FCSD 一项（见 SCOPE_STATEMENT.md）。

## 6. 限定说明（必须写进论文）

- “(2/3)^N + ε” 是已知最优攻击口径下的启发式陈述，不是紧约化。严格的知识可靠性抽取（重绕）会损失多项式因子，未计入上表。
- 本结论只覆盖：经典敌手、单用户、交互式顺序执行、诚实的最终验证者。不覆盖 Fiat–Shamir、并发/重置/中继攻击、量子敌手。
