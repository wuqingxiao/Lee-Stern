## P0 冻结判据（先做，后面所有阶段按它验收）
- 声明范围：经典、单用户/多用户（二选一）、严格顺序还是并发、是否含预计算。
- 成本单位：统一为比特操作（门数），注明内存成本模型。归约中"一次预言机调用=一步"换算为比特操作后约 2^177，假设 F 的工作量参数要按此改写。
- 验收线：每个攻击族在该工作量下成功率 <= 2^-136；启发式模型（格）额外要求 >= 16 位余量。
- 参考线：NIST 第 1 类为 2^143 门（AES-128 密钥搜索），本方案要求更高，需说明。

## P1 格攻击重算（关键路径，淘汰闸门）
- 安装 lattice-estimator（需要 Sage，Windows 上用 WSL2 或 Docker）。
- 用 C 的精确系数分布建 NoiseDistribution，跑 primal uSVP/BDD、primal hybrid（零猜测、MITM）、dual、dual hybrid。
- 用 fpylll 在 n=80..200 做小规模 BKZ 实验，检验 2016 判据对固定组成分布的预测。
- 本地启发式结果：usvp_2016_check.txt（n1024 β=891，core-SVP 2^260.2）；hybrid_budget_check.txt（2^166 内零猜测混合成功率 2^-474.2）。
- 闸门：n1024 最低代价 >= 验收线 + 16 位，否则回 P5 调整 C 或 n。
- 同步撤回 G1 数字；n640 geometric:2 淘汰，wide680/wide700 只剩约 16–18 位余量。

## P2 补齐未定价攻击族（n=1024）
- ISD+格混合：用 ISD 选坐标或猜部分取值，再对剩余维做格归约。
- 对偶攻击：格对偶区分器，以及编码侧统计译码（低重量对偶码字）。
- l1-BDD：Lee/l1 范数下的 BDD；说明 l2 嵌入是否已覆盖，或单独估计。
- 组成感知代数攻击：Arora–Ge 型（支持集 25 个取值），Groebner 复杂度估计。
- 复核已定价族在比特操作单位下的价格；补 Lee 度量 BJMM/表示法（Chailloux 等的一般重量函数译码）和 k-list 广义生日攻击。
- 闸门：全部族 >= 验收线。

## P4 归约范围
- 多用户：U=2^20 时总界约 2^-116。要么重做多用户归约（增加 N 或要求更小的 eps），要么在声明中限定单用户。

- 预计算/非一致敌手、并发会话：声明覆盖或明确排除。
- 闸门：定理 4.4 的修订版与 P0 声明范围一致，ledger 脚本全部 PASS。
