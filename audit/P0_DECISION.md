# P0 判据决定（推荐方案，2026-11-01）

采用 NIST 附加签名轮（CROSS、LESS、PERK 等）的"已知最佳攻击"口径，不以定理 4.4 的紧归约作为 128 位声明的依据。

## 声明
经典、单用户、交互式识别（不做 Fiat-Shamir 签名）。安全强度 λ = min(λ_snd, λ_FCSD, λ_hash) >= 128。

## 三项判据
1. 可靠性：每轮作弊成功率 2/3，N 轮为 (2/3)^N。N = 219 给出 2^-128.11（N = 218 为 2^-127.5，不够）。
2. FCSD 求解：所有已知攻击族的最低代价 >= 2^143 比特操作（NIST 第 1 类，等价 AES-128 密钥搜索）。格攻击另报 core-SVP，要求 >= 128。
3. 承诺：256 位哈希（SHA-256 或 SHA3-256）、256 位盐；经典碰撞 2^128。

## 理由
- 不需要假设 F(2^166, 2^-136)，也不需要处理"一次预言机调用=一步"换成比特操作后约 2^177 的单位矛盾。
- 多用户冒充：猜挑战的成功率与用户数无关。多目标密钥恢复最多带来约 sqrt(U) 的 ISD 加速，记为余量项。
- 第 6 章的测量配置（219 轮、SHA-256、32 字节盐）正好就是本口径下的安全配置；只需把组成换成冻结 C 后重测。
- 定理 4.4 保留为补充的条件结论，不作为声明依据。

## 对后续阶段的影响
- P1/P2：验收线从"2^166 内成功率 <= 2^-136"降为"代价 >= 2^143 比特操作"。本地启发式：n1024 core-SVP 2^260.2（余量约 117 位）。
- P4：多用户/并发/预计算只需在声明中写明范围，不需要重做归约。
- P6：主要是换组成后重测，代码改动最小。
