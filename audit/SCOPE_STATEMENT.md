## 1. 论文草稿：安全声明与范围

**参数。** p = 251，n = 1024，k = 512，公开完整组成 C 取冻结值（`F:\codex-pj\ac3\research\target_s\WP3_C_N1024.json`：w_C = 2025，log2|S_C| = 3460.236），识别轮数 N = 219，承诺哈希为 SHA-256，每个承诺使用新的 256 位盐。

**敌手模型。** 经典概率多项式时间敌手；单用户；交互式、严格顺序执行的识别；敌手可被动观察诚实会话后发起一次冒充；最终验证者诚实。

**不在范围内。** Fiat–Shamir 签名变体；并发、重置与中继攻击；量子敌手；侧信道。

**安全判据。** 采用 NIST 后量子征集中的“已知最优攻击”口径：经典 128 位要求每个已知攻击族的代价不低于 AES-128 密钥搜索（约 2^143 个经典门），格攻击的 core-SVP 代价（0.292β）不低于 128。

**安全等级。**

λ = min(λ_snd, λ_FCSD, λ_hash) = min(128.11, ≥ 244.1（core-SVP）/ ≥ 262.0（bit 运算）, 128) = 128

- λ_snd：(2/3)^219 = 2^-128.11（N = 218 时为 2^-127.52，不满足）。
- λ_FCSD：格族在悲观叠加下最低 core-SVP 244.1，MATZOV 代价 262.0；基线为 259.9 / 275.4。ISD 最低 777.6；代数族（Arora–Ge 4047.0、猜零 + Gröbner 2867.8）、ℓ1 代理 249.7 均高于门槛；n1024 下 coded-BKW 与对偶/对偶混合均不可行（196.5 与 897.1 属于 n640 geometric:2）。
- λ_hash：SHA-256 通用经典碰撞 2^128；隐藏性来自 256 位盐。

**多用户（仅作余量说明）。** U 个用户时，ISD 类攻击最多获得 √U 到 U 倍加速。U = 2^20 时按最坏情况扣 20 位，ISD 仍 ≥ 757 位，格攻击逐实例进行，代价不变（仍为 244.1 core-SVP），可靠性项与用户数无关。

**依据与补充结果。** 128 位声明基于已知最优攻击口径（见 SOUNDNESS_P0.md、MODEL_AUDIT.md、HASH_CHECK.md）。定理 4.4 的条件界（N = 256、h = 512、ρ = 384、假设 F(2^166, 2^-136)）作为补充的可证明结果保留，与本声明参数不同。

**未单独定价的攻击族。** 三层及以上的 BJMM 型 ISD；真正的 ℓ1 范数格约化（目前只有 ℓ2 代理）；量子攻击。前两项按已有的两层 ISD 与 ℓ2 代理有数百位余量，作为开放项披露。

**模型限定。** 固定范数秘密下的概率 BKZ 模型存在系统偏差（de Perthuis–Trenkić，IACR ePrint 2025/2195）。本文采用纳入 $k=60$ 后、由 $k=40$–$60$ 共 30 次小规模实验校准的 χ² 模型（KS $p=0.805$），它比固定范数模型预测更小的 β，对防守方更保守；k=60 的六次实验均已完成。
